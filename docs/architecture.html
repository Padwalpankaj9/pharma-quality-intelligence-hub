Pharma Quality Intelligence Hub

Standards-aligned architecture: GO-FAIR, Databricks Unity Catalog, MCP SDK v2, OWASP LLM/Agentic Top 10, and OpenTelemetry GenAI.

Layer 1: FAIR Data

OpenFDA + Unity Catalog

Bronze-Silver-Gold pipeline enforcing JSON Schema 2020-12 at runtime, SHA-256 lineage, CC0-1.0/MIT licensing, Delta NOT NULL/CHECK/PK constraints, and Unity Catalog SET TAGS.

Layer 2: Interfaces

MCP v2 & FastAPI RBAC

5 read-only MCP v2 tools with ToolAnnotations and Pydantic output schemas, 2 MCP resources (fair://metadata, fair://policy), and FastAPI with APIKeyHeader + constant-time key verification.

Layer 3: AI Safety

OWASP + OTel Telemetry

Tool-level RBAC (OWASP ASI03), Unicode NFKC normalization, indirect injection and HTML/image sanitization, and OTel GenAI telemetry logging trace_id, split tokens, and 401/403 denials.

Layer 4: Quality Gate

18-Case Evals & CI/CD

MCP v2 in-memory Client protocol tests, citation precision/recall/faithfulness, 0% guardrail false-positive rate, 0 RBAC leaks, and GitHub Actions CI with artifact upload.

Key Engineering Components

  • FAIR Data & Databricks Unity Catalog: metadata/data_contract.json (dataset PID urn:pharma-qih:dataset:gold_recalls:v1.0.0, 21 CFR 7.3 reference, ODCS SLA) enforced in Python and published to workspace.pharma_quality_fair with Unity Catalog SET TAGS and enforced Delta CHECK constraints.
  • MCP Server & Enterprise API: src/pharma_qih/mcp_server.py (MCP SDK v2.3 with read_only_hint=True, structured Pydantic outputs, and fair:// resources) paired with src/pharma_qih/api.py (APIKeyHeader OpenAPI auth, pagination, and 503 DB fault handling).
  • AI Security & Evaluation: src/pharma_qih/security.py defends against OWASP LLM01/LLM02/LLM05/ASI03; evals/golden_cases.json tests 18 stratified cases (accuracy, benign-tricky FPR, cross-role RBAC, direct and Unicode-obfuscated attacks).
  • Observability & CI/CD: src/pharma_qih/monitoring.py captures OpenTelemetry GenAI fields (trace_id, gen_ai_operation_name, split input/output tokens, error_type); .github/workflows/ci.yml gates every commit.

Architecture Decision Records (ADRs)

  • Unity Catalog Tags + TBLPROPERTIES: Unity Catalog SET TAGS powers workspace discovery and ABAC (FAIR Findable), while Delta CHECK constraints block invalid rows at write time (FAIR Reusable).
  • Guardrail False-Positive Rate (FPR): Measuring both 100% security recall and 0% FPR on domain queries (“drop in potency”, “union of trends”) ensures guardrails do not break legitimate Quality workflows.
  • Tool-Layer RBAC: Per OWASP Agentic Top 10 (ASI03), enforcing is_mcp_tool_allowed inside both the agent and MCP server guarantees least privilege across HTTP and stdio MCP.
